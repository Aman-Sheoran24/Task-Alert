How this differs from Google Photos Wardrobe

AI settings

Your key is never stored in this project or in the code. It is written to a file in your home folder, readable only by you:

It is never sent to the browser, never logged, and never sent anywhere except Google's Gemini endpoint. Delete that file, or press Remove below, and the app falls back to offline mode with every core feature intact.

Left blank, the app asks your key which models it can use and picks the best fast one automatically, so it keeps working when Google renames models.

Where to get a key

Important: a Google AI Pro / Ultra subscription is not the same thing as an API key, and does not by itself grant API access. API keys come from Google AI Studio and are billed separately — there is a free tier that is more than enough for this app's usage.
